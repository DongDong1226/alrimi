## 4. 중요한 결정과 이유 (되돌리지 말 것)

### 공람 기간이 지난 사업은 AI 해석을 보여주지 않는다
의견을 낼 수 없는 시점에 해석만 남아 잘못 참고되는 것을 막기 위함.
파일을 만든 날과 보는 날이 다를 수 있어 **화면에서 매번 날짜를 다시 판단**한다.

### AI는 번역만 한다
항목을 8개로 고정하고, 요약문에 없으면 `null`로 두고 "관련 내용이 없습니다"로 표시.
`app.js`의 `EIA_FIELDS`와 `build_data.py`의 `EIA_FIELDS` **키가 반드시 같아야 한다.**
(바꿨으면 `--full`로 다시 받아야 한다. 안 그러면 옛 키가 남는다)

### 도면(그림)을 읽어 노선을 뽑지 않는다
평가서 도면에 노선은 빨간 선으로 있지만 **좌표 격자가 없어 픽셀→위경도 기준점이 없다.**
틀린 노선은 없는 노선보다 나쁘다 — "우리 집 앞을 지나가나?"에 잘못 답하면 안 된다.
**대신** 요약문에서 하천 이름을 찾아 VWorld 하천망도(`LT_C_WKMSTRM`)에서 실제 도형을 받는다.

### 하천 사업에만 하천 노선을 붙인다
도로 사업 요약문에도 "지나가는 하천" 이름이 나온다. 그걸 그리면 틀린 그림이 된다.
`사업구분`·`근거법령`에 "하천"이 있을 때만 (`is_river_project()`).

### 환경영향평가의 위치 유형은 추측하지 않는다
전략환경영향평가는 면형/선형 표시가 있는데 환경영향평가는 **아예 없다**(확인함).
없으면 `locationTypes: []`로 두고 태그를 안 붙인다.

### 없는 값은 만들지 않는다
주민 의견 수, 설명회 참가 현황은 EIASS에서 수집되지 않는다 → 표시 안 함.
설명회 일시는 사업마다 자유 형식이라 **원문 그대로** 보여준다.

### 휴대폰용 사이트를 따로 만들지 않는다
주소도 둘, 고칠 곳도 둘이 되면 2~3명이서 못 따라간다.
같은 화면이 폭에 따라 바뀌게 한다(`app.css` 맨 아래 `@media (max-width:560px)`).
휴대폰에서는 데스크톱보다 **글자를 키우고**(`--tscale` .86→.95),
누르는 곳을 40~44px로 잡는다. 입력칸 글자는 16px 고정 —
그보다 작으면 아이폰이 입력할 때 화면을 확대해 버린다.

### 수집은 한국에서만 돌린다
EIASS가 해외 IP를 막는다(§5). 클라우드로 옮기려면 **한국 리전**이어야 한다.

## 5. 알려진 함정 (다 실제로 겪은 것)

| 함정 | 증상 | 대응 |
|---|---|---|
| **EIASS 해외 IP 차단** | GitHub Actions에서 `ConnectTimeout` (DNS는 풀리는데 TCP 무응답) | 수집은 한국 PC에서만. `collect.yml` 자동 실행 꺼 둠 |
| **VWorld 키 앞뒤 공백** | `INVALID_KEY`. **지도 타일은 나오는데 지오코더만 막힌다** | 코드 3곳에서 `strip()`. 키가 거부되면 **길이부터 세어 본다** |
| **`.bat` 줄바꿈이 LF** | 더블클릭해도 아무 일도 안 일어남 (로그에 첫 줄도 안 찍힘) | 반드시 CRLF. `.gitattributes`로 고정해 둠 |
| **배치 `ERRORLEVEL`** | 멀쩡한 실행이 "커밋 실패"로 끝남 | `echo`는 errorlevel을 0으로 안 되돌린다. 명령마다 바로 `%ERRORLEVEL%` 확인 |
| **목록 표가 두 개** | 모든 사업이 두 번씩 수집 → 비용 2배 | `parse_list_html`에서 사업번호로 걸러냄 |
| **목록이 날짜순이 아님** | 조기 중단으로 3분의 1 누락 | 공람 중인 사업 없는 페이지가 5쪽 이어질 때까지 넘긴다 |
| **AI 응답 잘림** | JSON 파싱 실패로 해석이 통째로 버려짐 | `max_tokens` 6000. 잘리면 `stop_reason`을 로그에 남긴다 |
| **VWorld 데이터 API `domain`** | `INCORRECT_KEY` | 발급 때 등록한 서비스URL과 글자 하나까지 같아야 한다 |
| **격자 `1fr` 이 상자보다 넓어짐** | 휴대폰에서 오른쪽이 **잘려 보임**(가로 스크롤도 안 생김 — `.hero{overflow:hidden}`이 잘라서) | `grid-template-columns:minmax(0,1fr)` + 자식에 `min-width:0`. `1fr`은 "가장 안 줄어드는 자식"에 맞춰 커진다 |
| **`hidden` 이 안 먹힘** | 관리자만 봐야 할 '노선 직접 그리기'가 늘 보였다 | 클래스의 `display`가 브라우저 기본 `[hidden]`을 이긴다. `[hidden]{display:none!important}`를 리셋에 넣어 뒀다 |
| **증분 수집이 옛 값을 붙잡음** | 설명회 일시가 `미정`으로 한 번 저장되면 영영 `미정` | `needs_detail_refresh()` — 아직 안 정해진 값이 있는 사업만 상세를 다시 받는다(PDF·AI 는 건너뜀). 지금 2/36건 해당 |
| **브라우저가 옛 app.js 를 붙잡음** | **배포는 됐는데 화면은 옛 코드로 돈다.** 고친 게 안 보여서 "코드가 잘못됐나" 하고 한참 헤맨다 (2026-08-02 겪음) | `index.html` 의 자산 주소에 `?v=dev` 를 달아 두고, `deploy.yml` 이 배포할 때 커밋 번호로 바꾼다. 로컬에서는 `?v=숫자`를 손으로 바꾸거나 **Ctrl+Shift+R** |
| **`file://`로 열기** | 표본 데이터로 대체됨 | 반드시 `python -m http.server 8000` |
| **EIASS 상세는 POST 전용** | 링크로 못 연다 | 숨은 폼을 만들어 제출 (`openEiassSource`) |
| **윈도우 cp949 콘솔** | 한글 로그에서 죽음 | 파이썬은 `log()`를 쓴다 |
| **시도가 16개** | 17개가 아님 | VWorld 자료가 최신이라 광주+전남이 "전남광주통합특별시"로 통합 |
