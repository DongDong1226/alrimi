## 1. 새 세션에서 처음 할 일 (환경 띄우기)

```bash
cd C:\dev\EIASS
python -m http.server 8000
```

브라우저에서 `http://localhost:8000` → 동네 선택 → 홈 화면.
(`file://` 로 열면 json을 못 읽어 표본 데이터로 대체된다. 반드시 서버로.)

- 관리자 진입: 첫 화면 맨 아래 "기후에너지환경부" 클릭 → 비밀번호 `admin1234`
- **내 PC에서는 지도가 안 보이는 게 정상이다.** `assets/config.js`가 비어 있어서다.
  보려면 관리자 화면에 `.env`의 localhost용 VWorld 키를 넣는다.
  (배포 사이트는 Actions가 키를 심어 주므로 그냥 보인다)
- `.env`에 `VWORLD_KEY`, `ANTHROPIC_API_KEY` 있음 — **확인함**
- 코드를 고친 뒤 로컬에서 확인할 때는 `index.html?v=아무숫자`로 열 것.
  안 그러면 브라우저가 옛 CSS/JS를 계속 쓴다(§5 함정 참고).

## 4. 중요한 결정과 이유 (되돌리지 말 것)

세부 규칙은 전부 `CLAUDE.md`에 있다. 여기는 **왜 그렇게 결정했는지**만 요약.

### 기준은 "공람 종료일"이 아니라 "의견제출 마감일" (2026-08-03 변경)
환경영향평가법 시행령 제38조: 공람이 끝난 뒤 7일 이내까지 의견을 낼 수 있다.
공람 종료일로 끊으면 아직 의견을 낼 수 있는 사업이 화면에서 사라진다.

### 단, 환경영향분석(AI 해석)만은 "공람 기간"에만 보여준다 ★ 헷갈리기 쉬움
평가서 초안 자체가 법적으로 공람 기간에만 열람 가능하다. 의견은 그 뒤에도 낼 수 있지만,
**해석은 공람 기간이 끝나면 바로 닫는다.** `viewOpen`(공람 중)과 `open`(의견 가능)을
코드에서 분리해 두었다 — 절대 하나로 합치지 말 것. `CLAUDE.md` "기간 규칙" §4 참고.

### AI는 번역만 한다
항목을 8개로 고정, 없으면 `null` + "관련 내용이 없습니다". 판단·홍보 문구 금지.

### 도면(그림)을 읽어 노선을 뽑지 않는다
좌표 격자가 없어 픽셀→위경도 변환 기준점이 없다. 대신 하천 이름으로 VWorld 하천망도에서
실제 도형을 받는다. 하천 사업에만 적용(도로 요약문의 "지나가는 하천" 이름과 구분).

### 선형 사업은 주소 한 점이 아니라 노선까지의 최단거리로 반경을 판단한다 (8/3 추가)
대표 주소가 노선에서 멀리 떨어진 경우가 흔하다(파주 주소, 계양구 코앞 노선 등).
노선 도형이 있는 사업만 해당(도로·철도는 여전히 주소 한 점).

### 휴대폰용 사이트를 따로 만들지 않는다
같은 화면이 폭에 따라 바뀐다. 주소도 코드도 하나로 유지해야 2~3명이서 따라간다.

### 수집은 GitHub Actions가 한다 — "EIASS 해외 IP 차단"은 틀린 결론이었다 (2026-08-06 뒤집음) ★

**이 항목은 원래 "수집은 한국에서만 돌린다 / EIASS가 해외 IP를 막는다"였다. 사실이 아니었다.**
같은 실수를 반복하지 않도록 어떻게 틀렸는지까지 남긴다.

**무엇이 틀렸나**
- 근거가 **2026-08-01에 딱 한 번 돌려 실패한 것** 하나뿐이었다. 재시도가 없었다.
- 원인을 밝히려고 `collect.yml`에 넣어 둔 '연결 확인' 단계는 **그 실패 뒤에 추가됐고,
  오늘까지 한 번도 실행된 적이 없었다.** 진단 도구를 만들어 놓고 써 보지 않았다.
- 그런데 결론은 `CLAUDE.md`·`HANDOFF.md`·`collect.yml` 세 곳에 "확인함"으로 박혔고,
  "다시 시도하지 말 것" 목록에까지 올라갔다. 그 뒤로 아무도 의심하지 않았다.
- 그 틀린 전제 위에서 **AWS Lightsail 이전(월 7천원 + 서버 관리)** 을 검토했다.

**실제로 확인한 것 (2026-08-05~06)**
- 전 세계 20개 노드 중 17곳 정상 — 미국 LA **0.49초**, 댈러스 1.09초, 독일·프랑스·네덜란드·러시아·인도·베트남
- GitHub 러너(미국 Azure)에서도 EIASS **0.23초**, VWorld 0.22초 정상
- `www.eiass.go.kr`은 AAAA(IPv6) 레코드가 없다 → IPv6 문제도 아니었다
- 다만 **간헐적으로 접속이 안 되는 것은 사실**이다. GitHub에서 3번 시험해 1번 성공:

  | 회차 | 러너 IP | 결과 |
  |---|---|---|
  | 1차 | `52.159.244.171` (San Jose) | DNS 조회 실패 (10초) |
  | 2차 | `9.234.149.180` (Boydton) | DNS는 됐는데 TCP 443 무응답 (20초) |
  | 3차 | `20.161.78.74` (Boydton) | 전부 정상 (0.23초) |

  **2·3차는 같은 데이터센터인데 결과가 달랐다.** 차단이라면 세 번 다 같은 지점에서 막혔어야 하고,
  실패 지점이 DNS·TCP로 제각각일 이유도 없다. 이건 차단이 아니라 불안정이다.

**그래서 어떻게 했나**
`build_data.py`에 재시도 통로(`SESSION`)를 두어 연결 실패 시 4·8·16초 쉬며 최대 4번 다시 시도하고,
`collect.yml`을 하루 두 번(09시·13시) 돌린다. 수집이 반쪽만 되면 커밋하지 않는 안전장치도 넣었다.

**교훈: 한 번 실패한 것을 "확인함"이라고 쓰지 말 것.** 특히 그 결론이 돈 쓰는 결정으로 이어질 때는.

## 5. 알려진 함정 (다 실제로 겪은 것)

| 함정 | 증상 | 대응 |
|---|---|---|
| **EIASS 접속이 간헐적으로 안 됨** | 어떤 날은 DNS 조회 실패, 어떤 날은 TCP 무응답 (**차단 아님**, §4) | `build_data.py`의 `SESSION`이 4·8·16초 쉬며 4번 재시도. 하루 두 번 실행 |
| **한 번 실패를 "확인함"으로 단정** | 틀린 제약이 문서 3곳에 박혀 반년 갈 뻔했다 (§4) | 제약을 문서에 넣기 전에 **두세 번 재현**해 볼 것 |
| **시험용 `--limit`이 진짜 데이터를 덮어씀** | `--limit 3`으로 돌리면 48건이 6건으로 줄어 그대로 커밋됨 | `collect.yml`이 `limit` 있으면 커밋 안 함 + 건수 급감 시 중단 |
| **VWorld 키 앞뒤 공백** | 지도 타일은 나오는데 지오코더만 `INVALID_KEY` | 코드 3곳에서 `strip()`. 거부되면 길이부터 세어 본다 |
| **`.bat` 줄바꿈이 LF** | 더블클릭해도 조용히 안 열림 | 반드시 CRLF. `.gitattributes`로 고정 |
| **배치 `ERRORLEVEL`** | 멀쩡한 실행이 "실패"로 끝남 | `echo` 뒤 말고 명령 직후 바로 확인 |
| **목록 표가 두 개 / 날짜순 아님** | 중복 수집·누락 | 사업번호로 중복 제거, 빈 페이지 5쪽까지 넘겨봄 |
| **AI 응답 잘림** | JSON 파싱 실패로 해석 통째 유실 | `max_tokens` 6000, 잘리면 `stop_reason` 로그 |
| **증분 수집이 옛 값을 붙잡음** | `미정`으로 한 번 저장되면 영영 `미정` | `needs_detail_refresh()` — 안 정해진 값 있으면 상세 재조회(PDF·AI는 건너뜀) |
| **브라우저가 옛 app.js를 붙잡음** | 배포는 됐는데 화면은 옛 코드 | 자산 주소에 `?v=커밋SHA`를 배포 때마다 자동으로 심음(`deploy.yml`) |
| **격자 `1fr`이 상자보다 넓어짐** | 휴대폰에서 오른쪽이 잘려 보임(스크롤도 안 생김) | `minmax(0,1fr)` + `min-width:0` |
| **`hidden`이 안 먹힘** | 클래스 `display`가 브라우저 기본을 이김 | `[hidden]{display:none!important}` 리셋에 추가 |
| **일시·장소 순서로 짝지으면 틀림** | 기장군 사업: 일시·장소 순서가 다름 | 지역 이름으로 매칭, 안 되면 원문 통째로 표시 |
| **`file://`로 열기** | 표본 데이터로 대체됨 | 반드시 `python -m http.server 8000` |
| **EIASS 상세는 POST 전용** | 링크로 못 엶 | 숨은 폼 제출 (`openEiassSource`) |
| **윈도우 cp949 콘솔** | 한글 로그에서 죽음 | 파이썬은 `log()` 사용 |
| **시도가 16개** | 17개가 아님 | 광주+전남이 VWorld 최신 자료 기준 통합됨 |
